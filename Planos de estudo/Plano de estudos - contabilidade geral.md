> **Concursos — Contabilidade Geral**
>
> Este arquivo nasce da separação do antigo `657_Concursos_contabilidade.md` (unificado), que tratava Contabilidade Pública e Contabilidade Geral como blocos de um único arquivo. A partir de agora cada uma é área própria dentro do eixo `concursos`, com arquivo .md dedicado — mesma lógica já aplicada quando Direito Tributário foi separado de Contabilidade.
>
> Fonte dos dados: scraping direto da área logada do usuário no Estratégia Concursos, curso "SEFAZ-BA - Contabilidade Geral" (Profs. Júlio Cardozo, Luciano Rosa e Silvio Sande), combo SEFAZ-BA (Auditor Fiscal - área Administração, Finanças e Controle Interno).
>
> Estrutura em **trilha sequencial**: cada aula (tipo `Aula`) é seguida de uma sessão irmã do tipo `Questões` cobrindo o mesmo assunto. Cada bloco termina em revisão mista (`simulado`).
>
> Mapeamento pro modelo de dados do Brita: `eixo = concursos`, `área = Contabilidade Geral`, `tipo = nome do bloco`, `conteúdo = título da sessão`, `dur = 60 (aulas) / variável (questões)`, `genero = "trilha"`.
